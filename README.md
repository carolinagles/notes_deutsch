# Deutsch lernen · Streamlit

Versión para Streamlit de la app incluida en `assets/Deutsch lernen.html`.
Conserva la interfaz, la navegación, la paleta pastel y las interacciones del HTML.
La descripción introductoria de la sección de verbos se elimina al cargar la app.

## Ejecutar

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```
